# Knowledge Blindspot Journal Output Template

Use this template when generating the markdown archive. Keep the content concise and evidence-based.

```md
# Knowledge Blindspot Archive

## Thread Summary
- Task:
- Output type:
- Mode: strict / review
- Archive path:

## Confirmed Blindspots
### 1. [Blindspot Name]
- blindspot:
- why_it_was_selected:
- evidence:
- explanation:
- correct_mental_model:
- how_to_apply:
- recommended_resources:
- next_step:

## Likely Blindspots
### 1. [Blindspot Name]
- blindspot:
- why_it_was_selected:
- evidence:
- concise_explanation:
- recommended_resources:
- next_step:

## Tentative Candidates
> Keep this section only in review mode.

### 1. [Candidate Name]
- blindspot:
- uncertainty:
- evidence:
- confirmation_needed:

## Not Archived
### 1. [Item Name]
- reason:
- evidence:

## Learning Actions
- Action 1:
- Action 2:
- Action 3:
```

Notes:

- Prefer concept-level labels over symptom-level labels.
- Keep the confirmed section short.
- If there are no confirmed blindspots, say so explicitly.
- If the user wants a final archive with minimal noise, omit `Tentative Candidates`.
